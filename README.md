# Путь к себе — Владивосток

Полноценный сайт психологического центра для предпринимателей и их семей. Проект включает публичные страницы, программы, специалистов, отзывы, формы заявок и административную панель.

## Стек

- Next.js / React / TypeScript
- Vinext и Cloudflare Workers
- Cloudflare D1 и Drizzle ORM
- адаптивная вёрстка без внешнего UI-конструктора

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

Проверки перед публикацией:

```bash
npm run lint
npm run build
```

## Структура

- `app/` — страницы, API и глобальные стили;
- `components/` — шапка, подвал, формы и интерфейсные компоненты;
- `lib/` — данные по умолчанию и серверный слой контента;
- `db/` и `drizzle/` — схема и миграции D1;
- `public/` — изображения и статические ресурсы;
- `scripts/build-pages-demo.mjs` — сборка безопасной статической демоверсии для GitHub Pages.

## GitHub Pages

Проект требует SSR, Cloudflare D1 и серверных API, поэтому полноценный движок нельзя запустить на GitHub Pages. В ветке `gh-pages` публикуется статическая демонстрация интерфейса.

Собрать её локально:

```bash
npm run pages:build
```

Результат появляется в игнорируемой директории `.pages-demo/`. Все страницы демоверсии содержат `noindex`, а `robots.txt` запрещает обход сайта.

В статической версии отключены:

- отправка форм и сохранение заявок;
- административная панель и редактирование контента;
- D1 и серверные API;
- серверная авторизация;
- динамические изменения из базы данных.

Полноценная версия должна размещаться на платформе с поддержкой Cloudflare Workers и D1.

## Запись, CRM, Telegram, оплата и расписание

На страницах всех специалистов размещены блоки записи с привязкой заявки к выбранному специалисту. В основном движке API `/api/leads` сохраняет заявки в D1 и показывает их в админ-панели. На GitHub Pages и техническом домене Beget пока опубликована статическая демонстрация: поля формы показаны для ознакомления, запись доступна через телефон и Telegram. CRM, Telegram-бот, платежи и календарь пока не подключены.

Для полноценного запуска нужны:

- Рабочий сервер приложения и база. Текущий движок предназначен для Cloudflare Workers/D1; обычная загрузка статических файлов на Beget не запускает его API. Для Beget понадобится отдельная серверная адаптация или подходящий VPS с поддержкой выбранного серверного стека. Основной домен должен работать по HTTPS.
- Выбранная CRM, её адрес, доступ для интеграции, воронка, ответственный и соответствие полей. Создание заявок поддерживают [REST API Битрикс24](https://apidocs.bitrix24.ru/api-reference/crm/leads/crm-lead-add.html) и [API amoCRM](https://www.amocrm.ru/developers/content/crm_platform/leads-api).
- Telegram-бот, созданный владельцем через BotFather, и чат сотрудников для уведомлений. Потребуются токен бота и ID чата. Секреты настраиваются только на сервере, не в исходниках и не в браузере. Отправка уведомлений — через [Telegram Bot API](https://core.telegram.org/bots/api#sendmessage). В сообщении достаточно номера заявки, имени, телефона и специалиста; описание психологического запроса остаётся в системе с ограниченным доступом.
- Для предоплаты: подключённый платёжный провайдер, реквизиты магазина и серверные ключи, утверждённые цены, размер предоплаты и правила отмены/возврата. Например, [ЮKassa](https://yookassa.ru/developers/payment-acceptance/getting-started/quick-start) поддерживает создание платежа и переход на платёжную страницу. Подтверждать оплату нужно по проверенному статусу на сервере; повторные уведомления не должны создавать повторные записи. Сначала тестовый режим, затем активация приёма настоящих платежей.
- Для свободных окон: единый календарь записи с графиком каждого специалиста, длительностью услуг, перерывами, выходными, часовыми поясами и отменами. CRM и календарь должны использовать один источник расписания. Если два клиента выбирают одно время, сервер бронирует его только одному. Скачивать приложение клиентам не требуется — запись может работать в браузере; сотрудникам нужен доступ к выбранной системе.
- Прямые публичные ссылки администратора в Telegram и MAX. Пока Telegram открывается по номеру через приложение; MAX ведёт на главную сервиса с указанием номера центра.
- Фото и видео для архива мероприятий. Раздел готов к наполнению; материалы ещё не предоставлены.

Предлагаемый порядок запуска: сервер и база → сохранение заявок → CRM и уведомления → расписание → тестовая предоплата → приём реальных платежей. Диагностическая сессия остаётся бесплатной; цены пакетов не выводятся до их согласования.

## Безопасность репозитория

`.gitignore` исключает `.env*`, локальные базы, `.wrangler`, `node_modules`, результаты сборки, логи, архивы и временные файлы. Секреты и реальные данные заявок не должны добавляться в Git.
